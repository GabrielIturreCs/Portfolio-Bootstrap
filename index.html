Sistema Odontológico

Descripción del Proyecto

Sistema web integral para consultorios odontológicos, desarrollado por un equipo de 6 personas. Me encargué de la integración del login con Google OAuth, el desarrollo del chatbot inteligente, el diseño de vistas para paciente y dentista, la conexión a base de datos Mongo Atlas, endpoints y tareas tanto de backend como frontend. Participé en la creación de cruds, edición, eliminación y creación de endpoints, así como el despliegue a producción de backend y frontend.

Funcionalidades Principales

  • Autenticación con Google OAuth 2.0, registro de usuarios, JWT tokens seguros y roles (Paciente, Dentista, Administrador)
  • Gestión de turnos: reserva, reprogramación, cancelación e historial
  • Pagos electrónicos con MercadoPago, procesamiento seguro y notificaciones automáticas
  • Dashboard admin con estadísticas en tiempo real, gestión de usuarios y reportes PDF
  • Chatbot inteligente integrado al sistema

Tecnologías y Herramientas

Angular Node.js MongoDB Atlas OAuth 2.0 JWT RxJS Mongoose Render.com MercadoPago
